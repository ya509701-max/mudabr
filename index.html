A Personal Story - From Financial Chaos to Control

Your Journey: From Paycheck to Paycheck to Financial Freedom

Imagine this scenario: You're a hardworking employee earning a decent salary every month. But here's the problem – by the 10th day of each month, your bank account is nearly empty. 😱

Sound familiar? You get your salary on the 1st, feel rich for a few days, spend on everything you want, and then realize you have nothing left to survive the rest of the month.

💡 The Solution:

You decide enough is enough! It's time to take control of your finances. You're going to build "Mudabbir" – your personal finance management dashboard that will help you track every penny and finally break the paycheck-to-paycheck cycle.

Here's a breakdown of the key sections you'll be building:

1
Overall Layout & Sidebar Navigation

A clean, organized interface where you can easily navigate between different financial tools and reports.

2
Header / Top Bar

Shows your profile, notifications about upcoming bills, and the Mudabbir logo.

3
Summary Cards

Current Balance, Monthly Income, and Expenses with percentage changes.

4
Recent Activities & Transactions

A detailed log of purchases, grocery bills, and subscriptions.

5
Monthly Bills Tracker

Upcoming payments with due dates and amounts.

6
Budget Overview

Set budgets for food, entertainment, and transport and track your spending.

7
Income vs. Expenses Chart

A visual representation of your weekly income versus expenses.

8
Payment Methods

Manage all your cards and payment accounts in one place.

9
Account Summary

A comprehensive view of checking, savings, and credit card accounts.

◎   Learning Goals

Assignment Objectives

This assignment will test your ability to build a complex, real-world financial dashboard layout using modern CSS. You will translate a design built with a utility-first framework into clean, vanilla CSS, focusing on CSS Grid, Flexbox, responsive design, and custom properties.

◎

Learning Outcomes

Build a complete, responsive financial dashboard using only HTML and vanilla CSS, demonstrating mastery of CSS Grid and Flexbox for layout, media queries for responsiveness, and a solid understanding of the box model, custom properties, and semantic HTML.

〈 〉
Implementing Modern UI Components

Recreate various UI components such as progress bars, cards with shadows, and styled tables. Apply advanced CSS properties for shadows, borders, and background gradients.

◎
Mastering CSS Grid and Flexbox for Layout

Implement various layouts using CSS Grid and Flexbox, including display:grid, grid-template-columns, justify-content, and align-items.

▤
Responsive Design with Media Queries

Write media queries to create a fully responsive design that adapts to different screen sizes, from mobile to desktop.

▥
Using CSS Custom Properties for Theming

Define and utilize CSS custom properties (variables) to manage colors, font sizes, and spacing throughout the dashboard.

✧
Styling with Pseudo-classes and Pseudo-elements

Enhance the user interface with pseudo-classes like hover, focus, active, and pseudo-elements.

☆
Creating Smooth Transitions and Animations

Apply transition effects and transform to create subtle visual effects and 3D credit card animations.
